# Writing style

- Use the Oxford (serial) comma only if it is necessary to avoid ambiguity, omit it otherwise.
  - Bad (unnecessary comma): "red, white, and blue".
  - Good (ambiguous without the comma, could read as "John and Mary" describing "the speakers"):
    "the speakers, John, and Mary".
- Never use em dashes (—). Instead of an em dash, use parentheses, a comma, a colon or a semicolon.
  - Bad: "the fix works — but only on Linux".
  - Good: "the fix works (but only on Linux)".
- Avoid hype/marketing words. Use plain and explicit language, as in engineering or scientific writing. Specific over abstract.
  - Bad: "a powerful, cutting-edge solution".
  - Good: "a solution that reduces query latency by 40%".
